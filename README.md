# Aeterna Noctis 한글패치

Windows판 본편·DLC 텍스트 한글패치입니다. 원본 게임 파일은 포함하지 않습니다.

구성: `translations/`는 한국어 번역 데이터, `scripts/`·`font/`·`release/`는 제작·설치 소스입니다. 설치용 ZIP은 [Releases](https://github.com/yoodong724/AeternaNoctis-ko/releases/latest)에서 받으세요. 소스 빌드는 [BUILD.md](BUILD.md)를 참고하세요.

## 설치

1. 게임을 종료하고 ZIP을 게임 폴더에 풉니다.
2. `AeternaNoctis-ko/install.cmd`를 실행합니다.
3. 게임 언어를 `日本語`로 선택합니다.

`Aeterna Noctis.exe`와 `AeternaNoctis-ko` 폴더가 나란히 있어야 합니다. 제거는 `uninstall.cmd`로 합니다. 기존 패치가 설치되어 있다면 먼저 제거하세요.

**패치 적용 후 작동은 확인했지만, 게임 전체에 걸친 검수는 완료되지 않았습니다.**
