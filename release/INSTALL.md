# Aeterna Noctis 한국어 패치 {{PATCH_VERSION}}

## 호환 빌드

- Windows x64
- Unity 2022.3.62f1
- build-guid `2afee6e7990049e895cb7917d9784414`
- 다른 빌드나 이미 수정된 리소스에는 설치되지 않는다.

## 설치

1. 게임을 종료한다.
2. ZIP을 게임 폴더에 풀어 `{{PACKAGE_NAME}}` 폴더가 `Aeterna Noctis.exe`와 나란히 위치하게 한다.
3. `{{PACKAGE_NAME}}` 안의 `install.cmd`를 더블클릭한다.
4. 설치기가 실행 파일과 리소스 네 개의 SHA-256을 확인한 뒤 원본 세 파일을 백업하고 패치를 적용한다.
5. 게임의 언어 설정에서 `日本語`를 선택한다. 이 패치에서는 일본어 슬롯이 한국어 슬롯이다.

```text
AeternaNoctis/                 ← 게임 폴더(실제 이름은 달라도 됨)
├─ Aeterna Noctis.exe
├─ Aeterna Noctis_Data/
└─ {{PACKAGE_NAME}}/
   ├─ install.cmd
   ├─ uninstall.cmd
   ├─ manifest.json
   ├─ patch/
   └─ bin/
```

설치기는 자신의 상위 폴더를 게임 폴더로 찾으므로 게임 설치 경로를 입력할 필요가 없다. ZIP 안에서 바로 실행하지 말고 압축을 모두 푼 뒤 실행한다.

패키지를 다른 곳에 둔 경우 명령 프롬프트에서 게임 폴더를 인수로 지정할 수 있다.

```bat
install.cmd "D:\Games\Aeterna Noctis"
```

해시가 다르면 설치기는 어떤 게임 파일도 수정하지 않고 중단한다. 관리자 권한은 게임 폴더의 쓰기 권한이 있을 때 필요하지 않다.

## 제거 및 롤백

1. 게임을 종료한다.
2. 설치할 때 사용한 패키지의 `uninstall.cmd`를 실행한다.
3. 설치기가 현재 한국어 파일과 백업 원본의 해시를 모두 확인한 뒤 원본을 복원한다.

패키지를 다른 곳에 둔 경우:

```bat
uninstall.cmd "D:\Games\Aeterna Noctis"
```

백업은 게임 폴더의 `.aeterna-ko-backup\{{PATCH_VERSION}}`에 생성되며 정상 제거 후 삭제된다. 설치 후 게임 리소스를 다른 모드로 다시 수정했다면 안전을 위해 자동 제거가 중단된다.

## 무결성 확인

패키지 내부의 `SHA256SUMS.txt`에는 `SHA256SUMS.txt` 자신을 제외한 모든 파일의 SHA-256이 있다. 배포 ZIP의 해시는 함께 제공되는 `{{PACKAGE_NAME}}-{{PATCH_VERSION}}.zip.sha256`에서 확인한다.

## 기존 한글패치가 설치되어 있는 경우

이 패키지는 원본 게임 파일을 기준으로 설치한다. 이전 패치가 설치되어 있으면 해당 패치의 제거기로 원본을 복원한 뒤 설치한다. 개발 후보 파일을 수동 교체했다면 먼저 기존 패치 파일을 되돌려야 이전 제거기의 해시 검사를 통과한다. 동일 패치의 중복 설치도 해시 검사에서 중단된다.

## 알려진 제한

현재 번역과 오프닝 자막 구간 조정을 포함한다. 패치 적용 후 작동은 확인했지만, 게임 전체에 걸친 검수는 완료되지 않았다. 세부 제한은 `KNOWN_ISSUES.md`에 기록했다.
