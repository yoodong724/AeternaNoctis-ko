# 알려진 제한 — {{PATCH_VERSION}}

패치 적용 후 작동은 확인했지만, 게임 전체에 걸친 검수는 완료되지 않았다.

- 사용자가 접근할 수 있었던 최종 후보 범위에서는 문제가 발견되지 않았다.
- 이미 지나갔거나 현재 저장에서 접근할 수 없는 대사 대부분은 실제 게임에서 재생 검수하지 못했다.
- Pit of the Damned, Boss Rush, Aeterna Lucis, Chaos Trials의 개별 실행 범위는 사용자 보고에서 특정되지 않았다.
- 빛/어둠 화살 라벨, 컨트롤러 할당 충돌 팝업, 일부 고속 이동 목적지와 선택지는 접근하지 못해 개별 확인하지 못했다.
- CSV 밖 하드코딩 TMP 후보 346종은 실제 표시 여부가 확정되지 않아 이번 패치에 포함하지 않았다.
- `CHARACTER.*` 171행과 이미지 텍스트는 1차 텍스트 한글화 범위 밖이다.
- 한국어는 별도 언어 항목이 아니라 기존 `日本語` 슬롯을 사용한다.
- 정확히 지정된 Windows 빌드에만 설치된다.
- 오프닝 한국어의 내용을 유지하면서 일본어 자막 구간에 재배치했다. 원본 일본어의 20~22번 자막이 같은 시각에 시작하므로 마지막 두 가시 구간에 내용을 나눴으며, 이 때문에 마지막 ‘삶에서 삶으로’ 반복 구절이 일본어 22번 기준보다 약 4초 늦게 표시된다. 실제 음성 싱크와 줄바꿈은 추가 실행 확인이 필요하다.

전체 번역은 자동 구조 검사와 독립 번역 검수를 통과했지만, 이는 미재생 범위의 실제 플레이 검수를 대신하지 않는다.
